# Spiegelau Perú

Sitio web comercial desarrollado para Spiegelau Perú, enfocado en mostrar su catálogo de cristalería y facilitar la búsqueda de productos mediante una interfaz sencilla y adaptable a distintos dispositivos.

## Funcionalidades

- Catálogo de productos organizado por categorías y colecciones.
- Filtros de navegación y páginas de detalle de productos.
- Diseño responsive para computadoras, tablets y celulares.
- Integración de Google Analytics 4 para el seguimiento de interacciones.
- Optimización SEO para mejorar el posicionamiento en buscadores.

## Tecnologías utilizadas

- **HTML5:** estructura de las páginas.
- **CSS3:** estilos y diseño responsive.
- **JavaScript:** funcionalidades e interactividad.
- **Vite:** entorno de desarrollo y compilación del proyecto.
- **Google Analytics 4:** analítica web.

## Instalación y ejecución

Para ejecutar el proyecto localmente, se necesita tener instalado Node.js.

1. Clonar el repositorio:

   `git clone https://github.com/GianpieroFlores/lcgroup-web.git`

2. Ingresar a la carpeta:

   `cd lcgroup-web`

3. Instalar las dependencias:

   `npm install`

4. Iniciar el servidor de desarrollo:

   `npm run dev`
